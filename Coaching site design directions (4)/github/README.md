# Off Script — coaching site

Static site, no build step.

- `index.html` — home page
- `parts-work.html` — parts work explainer

## Publish with GitHub Pages
1. Create a repo and upload these files to the root.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repo>/`.

Note: photos dropped into the image placeholders in the editor are not included — replace the placeholders with real `<img>` tags or re-export after adding images.
